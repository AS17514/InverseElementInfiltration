## 能力事件三选一面板（2026-08-23 本轮完成——验收见 docs/前端待办.md「本轮已完成」）

- `EventPanel` 新增能力模式专用分支（`_isAbilityPick` / `_abilitySelectionLocked`），普通事件原流程不变（ShowEvent → BuildOptions → OnOptionClicked → OnOptionSelected / ShowContinue / Complete）。
- 能力事件流程：`AbilityCandidatesDrawn → BuildAbilityOptions → SelectAbility / RefreshAbilityCandidate`。
- 监听 `GameEvent.AbilityCandidatesDrawn`，`OnDestroy` 对称退订。
- 能力候选/刷新次数从注入的 `GameState` **只读**；状态修改经 `Resolver.SelectAbility / RefreshAbilityCandidate`，UI 不本地改候选或次数。
- 选项区用现有 `UIComponentFactory.CreateEventOption` + `EventOptionView` 重建：**每个候选只有 1 个选择选项**（文本 `displayName + "\n" + description`）；刷新并入**长按选项按钮**（约 0.6s）——`EventOptionView.Bind` 新增可选 `onLongPress`（长按触发后吞掉抬起点击防误选；普通事件不传，行为不变）；剩余 0 次不挂长按（无效）。无独立刷新按钮（防事件界面选项溢出）。
- 描述末尾按策划要求追加："长按选项按钮刷新事件（刷新次数）" + 3 行"能力候选 N：能力名称（长按刷新 · 剩余 M 次） + 描述"（剩余次数来自 `GameState.AbilityRefreshLeft`，UI 只读）。
- 选择前先隐藏面板 + 防重复点击锁（`_abilitySelectionLocked`），再调 `Resolver.SelectAbility`（避免 `EventCompleted` 同步推进造成残留或重复点击）。
- 刷新后等 `AbilityCandidatesDrawn` 再重建整个选项区（不依赖本地状态）。
- 能力模式不调用普通事件的 `OnOptionClicked`/`OnOptionSelected`/`ShowContinue`/`Complete`；退出按钮在能力模式禁用（不沿用"直接完成"绕过选择）。
- `Bootstrap` 监听 `AbilityCandidatesDrawn` 处理首发唤醒；`LoadEventPanel` 完成后调用 `EventPanel.ShowAbilityEventFromState()` 主动回填（首发/读档路径，不依赖历史广播）；`OnDestroy` 对称退订。
- 未新增能力面板、能力候选 prefab、额外按钮；未改 UIPanels Addressables 注册。
- 资产恢复步骤（面板接好后人工在 Unity 执行）：① **工具 / 导入关卡配置（JSON）** ② **工具 / 收集全部配置到 Bootstrap**。
