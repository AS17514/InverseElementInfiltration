# 免费行动资格与执行（给前端）

> 日期：2026-08-19
> 后端已实现的机制说明 + **策划新诉求（执行方式待与前端商讨）**——本文是协作商讨入口
> 后端接口：GameState.FreeExecutes / 事件（ExtraActionGranted / BuffsChanged）

---

## 一、现状（后端已实现，2026-08-19 前）

| 项 | 说明 |
|---|---|
| 触发 | 棋子**击杀敌人**时获得"免费再动一次"资格（能力 `Ability_ExtraAction_OnKill_1`——刺客固有；效果模块 Effect-2 同款） |
| 表现 | 发 `ExtraActionGranted`（棋子 Id——UI 显示"免费行动"标记）+ `BuffsChanged` |
| 使用 | 下次执行该棋子**不扣 AP**（资格用掉即移除）——玩家可自行选择何时执行该棋子 |
| 有效期 | **待策划拍板**（质询第 1 问 a：限时作废 vs 保留到使用为止）——当前实现 = 保留到使用为止 |

## 二、策划新诉求（2026-08-19 确认）

> **免费攻击一次 → 必须立刻执行攻击**（策划诉求）：
> - 获得免费资格后**必须立刻执行攻击**——不能拖延、不能先操作其他棋子、不能用于移动
> - 具体执行方式（UI 交互/时序）**待与前端商讨**——后端暂未按此改（当前仍为"保留到使用为止"）

## 三、待商讨（前端参与）

1. **执行方式**：获得免费资格后如何"立刻执行攻击"？
   - 自动弹出目标选择（强制该棋子进入攻击选格）？
   - 强制锁定该棋子（其他操作禁用）？
   - 若该棋子当前无攻击目标（打不到任何人）——空放（玩家侧 A2b 语义：攻击必须执行可空放）还是等待？
2. **免费资格有效期**（质询第 1 问 a）：限时作废 or 保留到使用为止？
3. **多资格叠加**：同棋子连续击杀获得多个资格——当前 HashSet（1 个）语义是否够？

## 四、当前行为参考（未定案前的临时行为）

- 免费资格保留到使用为止（玩家自主决定何时执行该棋子）
- UI 已有"免费行动"标记（ExtraActionGranted/BuffsChanged）
- 后端改动点（若定案"立刻执行"）：BattleFlow 击杀结算 → 强制该棋子进入执行/选格流程——与前端商讨后实现
