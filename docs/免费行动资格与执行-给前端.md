# 免费行动资格与执行（给前端）

> 日期：2026-08-19
> 后端已实现的机制说明 + **策划新诉求（执行方式待与前端商讨）**——本文是协作商讨入口
> 后端接口：GameState.FreeExecutes / 事件（ExtraActionGranted / BuffsChanged）

---

## 一、现状（后端已实现，2026-08-19 前）

| 项 | 说明 |
|---|---|
| 触发 | 棋子**击杀敌人**时获得"免费再动一次"资格（能力 `Ability_ExtraAction_OnKill_1`——刺客固有；效果模块 Effect-2 同款） |
| 表现 | 发 `ExtraActionGranted`（棋子 Id——UI 显示"免费行动"标记）+ `BuffsChanged` |
| 使用 | 下次执行该棋子**不扣 AP**（资格用掉即移除）——玩家可自行选择何时执行该棋子 |
| 有效期 | ✅ **已确认（2026-08-19）：获得即立刻执行（插入性行动）——无"保留"语义**（当前实现仍为保留到使用为止——待执行方式定案后改） |

## 二、策划新诉求（2026-08-19 确认）

> **免费攻击一次 → 必须立刻执行攻击（插入性行动）**（策划确认）：
> - 获得免费资格后**立即执行攻击**——不存在"保留到使用为止"、不能拖延、不能先操作其他棋子、不能用于移动
> - 具体执行方式（UI 交互/时序）**待与前端商讨**——后端暂未按此改（当前仍为"保留到使用为止"）

## 三、待商讨（前端参与）

1. **执行方式**：获得免费资格后如何"立即执行攻击"？
   - 自动弹出目标选择（强制该棋子进入攻击选格）？
   - 强制锁定该棋子（其他操作禁用）？
   - 若该棋子当前无攻击目标（打不到任何人）——空放（玩家侧 A2b 语义：攻击必须执行可空放）还是等待？
2. **多资格叠加**：同棋子连续击杀获得多个资格——当前 HashSet（1 个）语义是否够？

## 三·五、免费行动的 buff 展示（2026-08-20——策划确认：放 Buff 栏可行）

> 用户转达策划（2026-08-20）：特殊能力/属性等**放 Buff 栏可行**——免费行动显示为两种 buff 的方案**策划认可**；具体形式（形状/位置/样式）仍可磋商。
> 后端描述文案已备（buffs-descriptions.json：能力本体 `ability_2119510590` / 触发 `free_execute`、`free_action_pending`）——前端 BuffDisplay 读表即可。

免费行动对应的应该是**两种 buff**（前端 BuffDisplay 需展示两层，且最好是两个独立的项）：

| 层 | 内容 | 展示 | 后端支撑 |
|---|---|---|---|
| **① 能力本身** | 该棋子具备"击杀敌人后可获得额外行动"的能力（刺客固有 / 效果模块 Effect-2） | 常驻 buff：'击杀后免费行动一次' | `GetAllAbilities` 含 ExtraAction（✔） |
| **② 触发后的效果** | 当前**有一个待执行的额外行动**（获得后需立刻执行的行动——策划确认语义） | 临时 buff：'待执行的免费行动'（触发后出现，执行/用掉后消失） | `FreeExecutes` 状态 + `ExtraActionGranted`/`BuffsChanged` 事件（✔ 前端据状态显示） |

- 这两个 buff **都要有**——能力本体常驻显示，触发后把"待执行"状态也显示出来（让玩家知道"现在有一个免费行动等着用/立刻执行"）
- 具体形状/位置/样式：前端按策划需要自定
