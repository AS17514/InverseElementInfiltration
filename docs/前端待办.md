## 后端排查记录（参考——独立栏目，不影响上面的待办列表）

> 后端排查发现、涉及 UI 侧的条目集中放这里——按需处理即可，不占用你自己的待办节奏。

- **遗物提示 ✨ 字符缺字形（2026-08-13）**：EventPanel.OnRelicObtained 的提示文案用了 `✨`（U+2728），当前字体（AlibabaFangYuan_SDF_48）不含该 emoji 字形——运行时显示为 □ + 每次获得遗物刷一条 TMPro 警告日志。可参考修法：换成字体内的字符（如 `【获得遗物：xxx】`），约 1 行
- **拖拽中手牌 hover 干扰（体验小项，可留意）**：拖拽卡片期间，手牌区仍按槽位切换 hover/让位插值——被拖的卡可能受布局插值干扰。若实测拖拽手感受影响，可参考：拖拽期间冻结 hover（HandLayoutController 加拖拽中标记跳过 UpdateHoverBySlot）
- **表现播放中退出中断协程（防御参考）**：退出/收尾时 DestroyImmediate 销毁控制器会杀死播放中的表现协程——规则层已有 ResetState 兜底（新局统一重置），可达路径均被兜底，链条脆弱但当前无实际影响。若未来表现链变复杂，可留意"销毁前等队列排空"
- **战斗面板阶段按钮恢复显示（参考——做第 2-4 层衔接时留意）**：目前第 1 层是最后一层（胜利即通关回主菜单），不会遇到。等做后续层时有一个衔接点可留意：中途胜利（打完本层战斗但未通关）会复用旧战斗控制器，而"结束准备/结束回合"按钮在战斗结束（GameOver）时被隐藏、新一场战斗没有恢复显示——届时摆放阶段会缺按钮、无法结束摆放。可参考修法：RefreshPhaseButton 的 Placement/PlayerTurn 分支补 `btn.gameObject.SetActive(true)`（约 2 行）
- **旧控制器楼层脏数据（参考——与上条同场景）**：中途胜利复用控制器时，回合进度条/波次节点沿用上一层的配置（`RefreshTurnProgress` 的 `_floor` 只在首次加载一次）。做后续层衔接时若发现进度条/波次节点与当前层不符，可参考修法：PhaseChanged(Placement) 时重置 `_floor/_waveDefs/_waveNodes/_lastTurnCount` 并重建节点
- **结算面板同帧按键（第 1 层也可能遇到的小体验点，可留意）**：战斗结束的那次点击（鼠标按下帧）与结算面板弹出同帧——面板开始检测按键时可能把这次点击当成"确认"，结算画面一闪而过、来不及看清胜负得分。若实际游玩中遇到，可参考修法：PushOverlay 后先跳一帧再开始按键轮询（约 2 行）
