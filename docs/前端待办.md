## ⚠️ 战斗交互缺陷：效果模块棋子选中无范围预览（2026-08-23 后端定位，修复方案已附——可参考方案实现）

- 【现象】选中炮手/盾兵/刺客时，**不显示任何移动绿块/攻击红框范围**（棋子似乎"点不动"）；但点击棋盘格子仍能正常移动/攻击——即"没高亮但能执行"。
- 【受影响棋子】3 个——全部是"默认程序最上方带**效果模块**"的棋子：
  - 盾兵 `[Effect#1护盾 → Move#4 → Melee#1]`
  - 刺客 `[Effect#2免费行动 → Move#7 → Melee#8]`
  - 炮手 `[Effect#3十字 → Arcing#10 → Move#9]`
  - （其余 9 个棋子程序开头是动作槽——不受影响）
- 【根因】`BattleController.PreviewRange`（约 L540）选中棋子后**只 `switch (program[0])`**：
  ```csharp
  switch (program[0])
  {
      case MoveTemplate move:   ShowHighlights(移动候选, null); break;
      case AttackTemplate atk:  ShowHighlights(null, 攻击候选); break;
      default: ClearHighlights();  // ← Effect 槽落这里：什么都不显示
  }
  ```
  效果模块（2026-08-19 落地：动作序列中不产生行动、装配即生效）让程序开头变成了 Effect，但此处仍假设"第 0 槽 = 动作槽"。**规则层/镜像执行链（`BattleFlow.AdvanceSlot`、`TryExecuteSelected`、`AdvanceExec`）均已正确跳过 Effect——唯独显示链漏了**，所以"能执行但无预览"。
- 【修复】将 `PreviewRange` 改为**镜像预推进**——与同文件 `TryExecuteSelected`（约 L573-581）逐字节同款的跳过判定，找到**第一个有候选的动作槽**再显示（顺带收益：显示范围与点击执行时校验的范围完全一致）：
  ```csharp
  /// <summary>选中后显示首个"有候选"逻辑块的范围（移动=绿块；攻击=红框）——
  /// 镜像预推进（与 TryExecuteSelected/规则层 AdvanceSlot 同款跳过判定）：跳过 Effect/Skip/无候选槽（2026-08-23 修复）。</summary>
  void PreviewRange(int pieceId)
  {
      var piece = _state.GetPiece(pieceId);
      if (piece == null) return;
      var program = piece.GetProgram(_state);
      if (program == null || program.Count == 0)
      {
          ClearHighlights();
          return;
      }
      // 镜像预推进：与 TryExecuteSelected/规则层同款——保证"显示的范围"与"执行校验的范围"一致
      int index = 0;
      while (index < program.Count)
      {
          var s = program[index];
          if (s is SkipTemplate) { index++; continue; }
          if (s is EffectTemplate) { index++; continue; } // 效果模块：不产生行动（装配即生效）
          if (s is MoveTemplate mm && _intentResolver.GetMoveOptions(_state, piece, mm).Count == 0) { index++; continue; }
          if (s is AttackTemplate aa && _boardRules.GetAttackableCells(_state, piece, aa).Count == 0) { index++; continue; }
          break;
      }
      if (index >= program.Count)
      {
          ClearHighlights(); // 全程序无有范围槽——无高亮（与执行"全跳过收尾"一致）
          return;
      }
      switch (program[index])
      {
          case MoveTemplate move:
              ShowHighlights(_intentResolver.GetMoveOptions(_state, piece, move), null);
              break;
          case AttackTemplate atk:
              ShowHighlights(null, _boardRules.GetAttackableCells(_state, piece, atk));
              break;
          default:
              ClearHighlights(); // 兜底
              break;
      }
  }
  ```
- 【修复后预期】盾兵/刺客选中显示 Move 绿块；炮手选中显示 Arcing 红框；其余棋子行为不变；被围时（移动无候选）自动跳到后续攻击槽显示红框——与执行链一致。
- 【范围】仅改 `BattleController.cs` 一个私有方法（约 +15 行）；规则层/数据层/资产/存档零改动；编译验证：选中三棋子看预览 + 执行一次确认范围一致。
