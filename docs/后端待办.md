## 5. 多次重开：BattleFlow 表现/执行字段跨局残留（2026-08-12，前端子代理交叉排查确认）

**现象**：多次重开后，新局战斗表现链路偶发卡死——敌方回合 `TryEndEnemyTurn` 永远等表现（`_waitingPresentation=true`），攻击闪烁/移动/部署动画不播（用户实测：攻击闪烁失效）。

**根因**：`StartBattle`（BattleFlow.cs:90-99）只重置 `_deployedWaveIndex/_waveEnded/EnemyAPMax/WaveEndCountdown`——以下字段**未清**：
- `_ctx`（执行上下文——上局 GameOver 时执行中则残留）
- `_waitingCellSelect`（选格等待）
- `_waitingPresentation`（表现等待——残留则新局敌方回合永远等表现）
- `_enemyTurnEndPending` / `_hadEnemyPresentation`（敌方回合收尾挂起）
- `_deployedThisRound`

上一局 GameOver（EndBattle 只发事件，不清理表现字段）时若表现/执行中途 → 残留进新局。概率性触发（取决于 GameOver 瞬间是否表现中途），但一旦触发新局战斗即卡死。

**建议修法**：`StartBattle` 开头统一重置上述字段（与 `_deployedWaveIndex = 0` 同处，约 5 行）。⚠️ 不要动 `_battleEnded` 标志（该标志专防 ResetForNewRun 破坏 GameOver 防御——保留原语义）。

**位置**：`Assets/_Project/Gameplay/BattleFlow.cs` — `StartBattle`
**改动量**：约 5 行
**阻塞**：是（多次重开完整性的关键项——前端无法绕过，UI 只能等 PresentationFinished）

## 6. AOE 攻击命中目标不闪白（2026-08-12）

**现象**：MeleeAOE 攻击命中目标无闪烁表现（普通攻击正常闪白）。

**根因**：`ResolveMeleeAOE`（Resolver.cs:113-134）发 `DamageDealt` 事件时 `TargetId` 未赋值（int 默认 0）→ UI `GameObject.Find("Piece_0")` 找不到（棋子 id 从 1 起）→ PlayDamage 跳过闪烁。

**建议修法**：`ResolveMeleeAOE` 遍历每个命中目标时，`DamageInfo.TargetId` 赋值为该目标棋子 id（与 `ResolveAttack` 单目标路径一致）。

**位置**：`Assets/_Project/Gameplay/Resolver.cs` — `ResolveMeleeAOE`（约 113-134 行）
**改动量**：1 行
**阻塞**：否（任何一局 AOE 都不闪，非重开特有，但视觉缺失）

## 7. EditorSession 快照/撤销栈跨局残留（2026-08-12）

**现象**：新局棋子编辑面板"恢复原样"（RestoreOriginal/RestoreAll）可能恢复到**上一局**的初始快照。

**根因**：`_initialSnapshots` / `_undoStacks`（EditorSession.cs:15-16）为实例字典，跨局不清；`BeginEdit` 的 `if (!_initialSnapshots.ContainsKey(defId))`（26 行）——新局同 defId 沿用旧局快照。

**建议修法**：新局开始时清空两个字典（`ResetForNewRun` 或编辑器面板首次打开时重建快照）。

**位置**：`Assets/_Project/Gameplay/EditorSession.cs` — `_initialSnapshots` / `_undoStacks`
**改动量**：约 2 行
**阻塞**：否（编辑功能瑕疵，可排期）
