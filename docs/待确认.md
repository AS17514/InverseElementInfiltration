## 已确认决策

- WipeOut 胜利语义按关卡配置决定；后端待办负责提供配置化实现。
- 编辑候选当前使用事件级模块池：移动 / 攻击 / 效果各抽 2 个，无放回；池不足时实际数量可少于 6。外部候选由事件共享，内置差集按棋子计算。
- 敌方升变预告只显示在棋子本身：肖像描边 / 脉冲；顶部或波次区域不额外显示。新手教程解释升变波次概念。
- 谢幕面板是首次通关后的独立 Thanks for playing / 结局报幕，暂缓制作。
- `OnTargetSelected` 保留为长期能力，不列近期开发任务。
- 计分常规结算时机为敌方回合结束；失败、终局、强制判定允许必要兜底。
