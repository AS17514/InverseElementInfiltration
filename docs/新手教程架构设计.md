## 1. 目标与表现形态（用户定案）

- 角色说话式教程：立绘（头像）+ 文本框，两个**独立对象**，需保持间距与有意识的对齐。
- 头像框 + 文本框**时刻在玩家屏幕内**（越界自动收拢）。
- 玩家**按任意键**切下一步；上一步/下一步切换用 DOTween 移动两个框。
- 遮罩高亮：任意对象（**场景对象或 UI 对象**）可被遮罩框住；shader 实现——中间不变、四周压暗；框默认刚好框住对象，**框与对象间距可调**。

## 3. 前端架构（UI.asmdef，三层）

### 3.1 TutorialManager（控制器，单实例，Bootstrap 创建）

职责：
- 持有步骤序列定义（`TutorialStep` 列表，文案来自策划 docx，暂存代码，定稿后可迁 JSON）。
- 观察 EventCenter 既有事件（只读），命中激活条件 → 展示对应序列。
- 管理 TutorialMask + TutorialPanel 生命周期（PushOverlay 冻结可选）。
- 去重：会话内 `HashSet<string>`；持久化待后端契约（见 §5）。
- 输入：任意键/点击 = 下一步；上一步支持（方向键上/左 + 面板按钮占位）。

### 3.2 TutorialMask（遮罩高亮）

- Shader：`Assets/_Project/UI/Shaders/TutorialMask.shader`（已建）——全屏 UI Image + 自定义材质；frag 内按像素坐标判断是否在挖孔矩形内，孔内 alpha=0（中间原样），孔外 `_DarkColor` 压暗。
- 组件 `TutorialMask.cs`：
  - 运行时自建全屏 Canvas（ScreenSpaceOverlay，sortingOrder 顶层，如 20000）+ Image（raycastTarget=false）。
  - `SetTarget(target, padding)`：支持 RectTransform（GetWorldCorners → 屏幕矩形）与 Renderer（bounds 8 角 → Camera.main 屏幕坐标）；无相机兜底。
  - LateUpdate 刷新 `_HoleRect/_Padding/_DarkColor`；`ClearTarget()` 全屏压暗。
  - padding 可 DOTween 缓动（入场/出场）。
- 兼容性：ScreenSpaceOverlay 下 uv×屏幕像素 = 像素坐标，无需按 Canvas 缩放换算。

### 3.3 TutorialPanel（角色说话面板，李毕拼 prefab，Key="Tutorial"）

节点契约（FindDeep 容错解析）：
- `Img_Portrait`：角色立绘（差分切换 = 换 sprite）
- `Txt_Speaker`：说话人（如 "Xeon"/"3号"）
- `Txt_Text`：台词（逐字打字机，参考 StoryPanel）
- `Grp_Portrait` / `Grp_Text`：**两个独立框体**，各自锚点定位

行为：
- 每步定义布局预设（头像/文本框锚点 + 偏移 + 间距）；切换步骤 = 两框 DOTween 移动到新预设位。
- 屏幕内保持：计算 Canvas 尺寸，对 anchoredPosition 做 clamp（含安全边距）。
- 任意键/点击下一步；输入由 TutorialManager 统一收口，面板只做展示与动画。
- 立绘按 key（"xeon"→常态/惊讶/坏笑差分、"no3"）查表，缺省隐藏/兜底（美术资源未交付前可只显文本）。

### 3.4 TutorialStep 数据（代码配置）

`id / onceKey / speaker / portraitKey / text / highlightTarget(string) / highlightPadding / portraitPos / textPos / trigger(事件谓词) / next`

## 4. 激活点映射（docx 顺序 → 既有事件，子代理侦察后补 file:line）

| 步骤（docx） | 激活条件（前端观察，只读） | 高亮目标 |
|---|---|---|
| 剧情结束进事件界面，介绍事件 | 首次 EventOpened（新局） | 事件面板 |
| 选择遗物后介绍遗物 | RelicObtained | 遗物/能力栏 |
| 进入棋子编辑界面 | 编辑面板打开事件 | 编辑面板模块区 |
| 推出编辑进牌组构筑 | 构筑面板打开事件 | 卡牌列表/合成区 |
| 进入战斗：手牌/部署 | PhaseChanged→Placement | 手牌区+前两排格 |
| 点击已部署棋子 | 首次棋子点击（UI 观察） | 棋子信息区 |
| 左侧信息区/右下角/友伤 | 时序步骤（上一句后） | 对应 UI |

> 备注：高亮目标用场景/UI 节点路径字符串，TutorialManager 按需解析（FindDeep / GameObject.Find / 名称池），解析失败跳过高亮不阻塞。
