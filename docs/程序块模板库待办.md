## 现状（2026-08-09 排查结论——已被实施解决）

**原问题**：测试数据中没有"独立程序块/模板定义"——全部程序块都内联在棋子数据里（无独立模板文件/无 Template 资产/无模板注册表）。

**✅ 已实施（2026-08-09，后端）**：
- `Assets/Data/Templates/templates.json`：20 条独立模板（19 种现有编号结构 + 新增 **Attack-11**"攻击[后·左·右选一格]"）
- `TemplateDef`（SO 包装类：templateKey + Template）+ `TemplateLibrary`（按"种类+编号"查询注册表）
- `ConfigImporter` 扩展：读模板 JSON → `Assets/Settings/Configs/Tpl_{type}_{id}.asset`（增量模式）
- `EditorSession.GetAvailableTemplates`：候选 = 棋子自带 ∪ 模板库（按 id 去重）
- `Bootstrap`：+ `_templateConfigs` 拖拽列表 → LoadConfigs 注册 TemplateLibrary

**设计决策**：① 模板资产化用包装类（遵循"数值配置→SO"）；② 模板库与棋子内联**独立并存**（内联=默认程序、模板库=编辑可选池，语义不同不合并）
