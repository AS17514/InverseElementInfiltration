# 能力事件显示：修复参考与体验观察（2026-08-23）

> 背景：实测发现能力事件相关两处显示问题；已定位根因并做一轮临时修改验证（验证通过）；临时修改已回退，本文为修复参考（含完整方案代码）与两条体验观察。

---

## 一、问题与根因

**问题 1：能力事件界面"候选项重复显示"（文本+按钮两份，视觉叠加）**
- 根因：`EventPanel.DescribeAbility()` 把候选清单以**文本**写入描述区，`BuildAbilityOptions()` 又以**按钮**在选项区生成一份——同一批候选两处渲染。
- 位置：`Assets/_Project/UI/Views/EventPanel.cs`

**问题 2：战斗左侧"已获得能力"不显示（两个原因叠加）**
- 根因 A：`BattleController.BuildRelicIcons()` 从 Addressables 加载 `"Image"` 模板——该 prefab 已删除（此前 UI 清理提交），加载恒失败 → 遗物列表永空。
- 根因 B：`BattleController.RefreshEventAbilities()` 只遍历 `relic.abilities`（旧特殊能力模型）——新能力为 `RelicEffectSpec` 效果组合、该字段为空 → 名字不产出。
- 位置：`Assets/_Project/UI/BattleController.cs`

## 二、修复方案（已验证过，可直接采用）

### 1. `EventPanel.DescribeAbility()`——去掉文本区候选清单

候选项只由选项按钮区展示；描述区保留事件描述与操作提示：

```csharp
/// <summary>能力描述：事件描述 + 操作提示；候选清单不移入文本区（与按钮区重复渲染导致叠加）。</summary>
string DescribeAbility()
{
    var sb = new System.Text.StringBuilder(Describe(_currentEvent));
    sb.AppendLine();
    sb.AppendLine();
    sb.Append("长按选项按钮刷新事件（刷新次数）");
    return sb.ToString();
}
```

### 2. `BattleController.BuildRelicIcons()`——弃用已删除的 "Image" 模板，代码生成色块

```csharp
System.Collections.IEnumerator BuildRelicIcons(int gen)
{
    // 原 Addressables "Image" 模板已删除（断链）——改为代码生成色块，不依赖 prefab
    if (_relicDisplay == null || _state == null) yield break;
    if (gen != _relicListGen || !_relicListShown) yield break;
    foreach (var relic in _state.Relics)
    {
        var go = new GameObject($"RelicIcon_{relic.name}");
        go.transform.SetParent(_relicDisplay, false);
        var img = go.AddComponent<UnityEngine.UI.Image>();
        if (img != null)
        {
            img.color = ItemGettingPanel.RelicTint(relic); // 占位色块（与获取弹窗同色）
            img.raycastTarget = true;
        }
        var hover = go.GetComponent<RelicIconHover>();
        if (hover == null) hover = go.AddComponent<RelicIconHover>();
        hover.Init(relic);
    }
}
```
（相应删除 `_relicIconTemplate` 字段声明——已无使用。）

### 3. `BattleController.RefreshEventAbilities()`——新模型兼容（回退 displayName）

```csharp
if (_state.Relics != null)
{
    foreach (var relic in _state.Relics)
    {
        if (relic == null) continue;
        // 新能力模型（RelicEffectSpec 组合）无 abilities——回退显示遗物 displayName
        if (relic.abilities != null && relic.abilities.Count > 0)
        {
            foreach (var ability in relic.abilities)
            {
                if (ability == null) continue;
                string name = DisplayNames.OfAbilityType(ability.type);
                if (!names.Contains(name)) names.Add(name);
            }
        }
        else if (!string.IsNullOrEmpty(relic.displayName))
        {
            if (!names.Contains(relic.displayName)) names.Add(relic.displayName);
        }
    }
}
```

## 四、体验观察（供前端同学参考）

1. **道中能力栏只显示能力名，没有效果描述**——玩家拿到"过目不忘"只看到名字，看不到"行动点上限+1；抽牌额外一张"这类效果说明。可考虑在能力栏 hover/展开时显示 `RelicDef.description`。
2. **能力事件界面描述文本会溢出边框**，且可能与下方文字/边框叠压；另外**每个候选当前的刷新次数未显示**（现状一个选项可刷新一次，次数用尽后长按无反应但不提示）。溢出与刷新次数提示可作为后续打磨项（优先级靠后）。
